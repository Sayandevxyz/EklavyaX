# EklavyaX React frontend

This is the new React/Vite frontend shell for EklavyaX. It currently owns the landing page, Student and Teacher authentication, and the first role dashboards while the legacy static pages remain available in `../frontend` during migration.

## Run locally

1. Start the FastAPI backend on port 8000.
2. Run `npm install` in this directory.
3. Run `npm run dev`.
4. Open `http://localhost:5173`.

Set `VITE_API_BASE` when the API is hosted separately.
